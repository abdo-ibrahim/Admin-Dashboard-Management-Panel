# Admin Dashboard - Management-Panel

A responsive and modern **Admin Dashboard** built using **React.js** and **Tailwind CSS**, designed to provide a clean and organized interface for managing content, users, and data efficiently.

---

## 🔗 Live Demo

👉 https://abdo-ibrahim.github.io/Admin-Dashboard-Management-Panel/

---

## Tech Stack

- HTML5
- CSS3

---

## 📌 Key Features

### Dashboard
- Overview of statistics and summaries
- Clean card-based layout
- Responsive design for all screen sizes

### Profile Management
- Edit user information
- Update personal data
- Organized profile sections

### Projects & Courses
- Display training courses
- Manage project data
- Structured content presentation

### Plans & Friends
- Manage subscription plans
- View and organize friends/users list
- Responsive tables and cards

### Files & Settings
- File organization interface
- Application configuration settings
- Clean UI with structured components

---

## 📱 Responsive Design

- Fully responsive across desktop, tablet, and mobile devices
- Built with Tailwind utility-first approach
