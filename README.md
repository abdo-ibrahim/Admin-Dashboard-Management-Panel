# Admin-Dashboard
Built a responsive admin dashboard using React.js, Tailwind CSS, HTML, and CSS, providing an organized interface for managing content and data.

Live Demo:
[https://abdo-ibrahim.github.io/Admin-Dashboard/](https://abdo-ibrahim.github.io/Admin-Dashboard-Management-Panel/)

Tech Stack
React.js, Tailwind CSS, HTML, CSS

Key Features
• Dashboard: Overview of stats and summaries
• Profile Management: Edit user information and personal data
• Projects & Courses: View and manage projects and training courses
• Plans & Friends: Manage subscription plans and user/friend lists
• Files & Settings: Organize files and configure application settings
